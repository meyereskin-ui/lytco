# LYTCO Mineral Resources — Website

Next.js site for LYTCO Mineral Resources Limited (Kapyanga, Mumbwa District, Zambia).

- `npm install` then `npm run dev` to run locally
- Content lives at the top of `app/page.tsx` (licences, commodities, platform pillars)
- Set `CONTACT_EMAIL` in `app/page.tsx` to show the contact button
- Set `SHOW_LICENCE_STATUS = false` to hide the licence status pills

Deploy: import this repository in Vercel (framework preset: Next.js).
